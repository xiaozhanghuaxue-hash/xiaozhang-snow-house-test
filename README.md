# 小张的雪屋 · 手机测试版

按照已确认的小程序视觉稿与业务规则制作的手机端内部测试版本。

该版本用于验证页面、录入流程和计算逻辑；正式微信登录、多用户隔离及真实业务数据不在本轮测试范围内。

## 2026-10-11 手机 UI 调整

- 首页去掉大标语；快速记录改为两列纯文字入口，最后一项占整行；底部导航使用纯文字。
- 缩紧表单间距，输入文字保持 16px，避免 iPhone 聚焦时自动放大。
- 打开弹窗后固定背景，限制横向溢出；弹窗标题与关闭按钮固定，仅内容区纵向滚动；取消和保存按钮保持可见。
- 监听可视区域尺寸，使弹窗适应键盘出现后的可用高度；保留底部安全距离。
- 浏览器验证：390×844、320×568 和 390×400；五个表单无横向溢出，保存按钮命中检查通过。尚需用户在 iPhone 飞书内复测真实键盘与滑动表现。
- 手机入口：https://xiaozhanghuaxue-hash.github.io/xiaozhang-snow-house-test/

下一步：先确认手机 UI，再逐项收集和调整功能问题。
