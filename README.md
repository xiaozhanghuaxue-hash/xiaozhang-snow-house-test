# 小张的雪屋 · 手机测试版

按照已确认的小程序视觉稿与业务规则制作的手机端内部测试版本。

该版本用于验证页面、录入流程和计算逻辑；正式微信登录、多用户隔离及真实业务数据不在本轮测试范围内。

## 2026-10-11 手机 UI 调整

- 首页去掉大标语；快速记录改为两列纯文字入口，最后一项占整行；底部导航使用纯文字。
- 缩紧表单间距，输入文字保持 16px，避免 iPhone 聚焦时自动放大。
- 打开弹窗后固定背景，限制横向溢出；弹窗标题与关闭按钮固定，仅内容区纵向滚动；取消和保存按钮保持可见。
- 监听可视区域尺寸，使弹窗适应键盘出现后的可用高度；保留底部安全距离。
- 浏览器验证：390×844、320×568 和 390×400；五个表单无横向溢出，保存按钮命中检查通过。尚需用户在 iPhone 飞书内复测真实键盘与滑动表现。
- 手机入口：https://xiaozhanghuaxue-hash.github.io/xiaozhang-snow-house-test/

## 2026-10-11 商品销售备注与数据保护

- 用户确认：持续优化不能影响已录入数据。商品销售新增可选备注，用来记录购买人、协助销售者等；保存后在销售记录中展开查看。
- 本次新增 `sales[].note`，旧记录缺少该字段时正常显示；沿用原网址及 `snow-house-mobile-v2` 存储键，不清空、不重建已有数据，不重算历史结算价。
- 验证通过：旧记录逐字段保持不变；读取页面不写入存储；新增销售不改变其他模块；新备注刷新后保留；多行及 HTML 特殊字符作为普通文本显示；手机尺寸的表单录入和查看已验证。
- 后续变更要求：界面修改不迁移数据；数据结构修改必须兼容旧格式，并在迁移前提供备份、回退及验证方案。不得为解决测试问题清理用户存储或更换存储键。
- 当前数据仅保存在所用浏览器/飞书网页容器的本地存储，并未接入云同步；清缓存、换设备或换网页容器存在数据不可用风险。导出/恢复功能目前仍待实现，不应视为已有备份。
