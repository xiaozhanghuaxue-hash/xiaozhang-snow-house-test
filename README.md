## 最新方案：本地保存、手机手动导出（2026-10-15，覆盖此前云端前置条件）

- 用户确认不接云服务，不要求账号或上传；按个人需要在手机直接导出。云账号不再是当前前置条件。
- 首页及后台上方提供“导出数据”，页面自动准备完整文件，点击“导出到手机”；支持时打开系统文件分享，否则尝试下载。恢复与校验折叠为次要入口。
- 当前文件为完整、未加密 JSON（非 Excel），包含七组资料、原始备注及发货原文、历史价格，不上传业务数据。
- `backup-core.js` 提供格式版本、结构检查与 SHA-256 完整性校验。校验不是身份签名或加密；文件应由用户妥善保管。
- 导出或分享不自动宣称文件已保存。需要验证时重新选择保存文件，匹配当前数据后记录校验状态；变化后的资料会提示再次导出。
- 恢复前预览、输入“覆盖恢复”；当前有资料时先备份并读回验证。保存恢复前原始副本后才替换，并读回核对；副本仅在同机，不替代外部备份。无合并、重算或自动云同步。
- 原存储键不变，页面加载不写入。损坏数据进入只读保护而不删除；保存失败撤回内存中的本次变更，保留表单；旧页面覆盖新记录被阻止。
- 已从后台移除常驻“清空全部数据”测试按钮，避免投入使用后误点。
- 验证：`tests/backup.test.cjs` 七类完整往返、原价与备注不变、损坏/不支持文件、非法字段、恢复确认、原资料备份前置、空间失败、读取损坏资料、跨页面变更保护；原清空回归测试通过。
- 浏览器已完成实际下载 JSON、重选该文件并显示校验通过；390×844 与 320×568 界面检查完成。真实 iPhone 飞书的下载/分享保存仍需用户验收，不能用电脑测试代替。
